# Node.js 24 for Mavericks

Node.js requires macOS 13 Ventura or later.

Instead, use this runtime (based on [Wowfunhappy's port](https://github.com/Wowfunhappy/Node-24-Mavericks) built for Mac OS X 10.9 Mavericks.

## Getting started

```sh
sudo installer -pkg nodejs-<version>.pkg -target /
```

In a new Terminal:

```sh
node-24 hello.js
```
